# Cloud Computing Mini App

A simple static web application for CSC 61004 System Paradigms, Tutorial 6.

## What it demonstrates
- IaaS, PaaS and SaaS
- CapEx vs OpEx
- Cloud scalability and cost efficiency
- A small interactive quiz

## Run locally
Open `index.html` in a web browser.

## Deploy with GitHub + Render
1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, and `script.js`.
3. Sign in to Render.
4. Create a new **Static Site**.
5. Connect your GitHub repository.
6. Use the repository root as the publish directory.
7. Deploy and copy the public URL.

## Deploy with Netlify
1. Push the files to GitHub.
2. Sign in to Netlify.
3. Add a new site from Git.
4. Select your repository.
5. Deploy with the default static-site settings.
